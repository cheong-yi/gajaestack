# Overlays

[typescript-best-practices.md](typescript-best-practices.md) is the upstream pstack `typescript-best-practices` body after its frontmatter, unmodified (see [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES)).

Insert it only into the `AGENTS.md` of a TypeScript repository, and only when that install is explicitly requested and run for that repository. Nothing in this kit inserts it automatically, and it is not part of the practice-role-sets plugin.
